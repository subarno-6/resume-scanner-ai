# AI Resume Scanner 🤖📄

This Streamlit app uses OpenAI's GPT to analyze a resume PDF and compare it against a job description, giving:
- Match percentage
- Strengths and weaknesses
- Final hiring verdict

## Tech Stack
- Python
- Streamlit
- OpenAI API
- pdfplumber (resume parsing)
- fpdf (PDF report generation)

## Usage
1. Upload a resume (PDF)
2. Paste a job description
3. Get a detailed analysis
4. Download the feedback as a PDF

## Deployment
- Push to GitHub
- Deploy on [Streamlit Cloud](https://streamlit.io/cloud)
